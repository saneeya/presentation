06

Do & Do Not

Do
Let the current-item name wrap to a second or third line — it's a real, editable textarea, so give it the height it asks for.
Reserve the left accent bar for nav-style selection (accordion rows, section headers). List rows signal selection with background fill alone.
Confirm before Delete Line Item executes, and keep it red. Edit and Duplicate share the accent blue; Delete never does.
Let one accordion section close when another opens — it keeps the panel short instead of stacking every field on screen at once.
Do Not
Don't truncate the name with an ellipsis — that hides the date range or market that made someone open the panel.
Don't use the accent color for anything destructive. Delete takes the danger token, full stop.
07

Accessibility

Four independent interactive parts — the list, the quick-actions menu, the accordion, and the editable name field. None of them borrow another's keys.

RRoles
  • Item list: role="listbox"; each row is role="option" with aria-selected
  • Kebab trigger: <button> with aria-haspopup="menu", aria-expanded
  • Pop-over: role="menu", items are role="menuitem"
  • Section header: role="button", aria-expanded — one section open at a time
  • Campaign name: a real <textarea> with aria-label="Campaign name", not a styled div
KKeyboard
  • ↑ / ↓ moves focus between rows
  • Enter / Space selects the focused row, or toggles a section header / the Current Line Item row
  • Enter on the trigger opens the menu, focus moves to Edit
  • In the name field, Enter commits and blurs instead of inserting a line break; Esc reverts focus
  • Esc closes an open quick-actions menu, focus returns to its trigger
FFocus
  • Every row, section header, and the kebab trigger show a 2px accent ring, offset 2px
  • Opening the menu never leaves the row's own focus ring visible underneath
  • Deleting a row returns focus to the row that took its place, or the panel head if the list is now empty
SScreen reader
  • Row announces as "Option, February dash Boston Metro, selected"
  • Trigger announces as "Line item actions, button, menu collapsed / expanded"
  • Section header announces as "Targeting, button, expanded"
  • Delete requires a confirmation dialog — it is never announced as complete on its own menu item

Code

Row markup and the state classes that drive it.

<!-- one row in the list — no border-left, color-fill only -->
<li class="li-row li-row--selected"
    role="option"
    aria-selected="true"
    tabindex="0">
  <span class="li-row__label">February – Boston Metro</span>

  <!-- opacity:0 until the row is hovered/focused -->
  <button class="li-row__menu-trigger"
          aria-haspopup="menu"
          aria-expanded="false"
          aria-label="Line item actions">•••</button>

  <!-- rendered on open, role="menu" -->
  <ul class="li-row__menu" role="menu" hidden>
    <li role="menuitem">Edit Line Item</li>
    <li role="menuitem">Duplicate Line Item</li>
    <li role="menuitem" class="is-danger">Delete Line Item</li>
  </ul>
</li>

/* rows: background-only states, no border, no weight change */
.li-row                        { background: #F7F9FA; }
.li-row:hover:not(.li-row--selected) { background: #D4DEE3; }
.li-row--selected              { background: #DDE9FF; }
.li-row--selected:hover,
.li-row--selected.is-open      { background: #B3CAF4; }

/* kebab: hidden until interaction, own hover chip */
.li-row__menu-trigger           { opacity: 0; color: var(--accent); }
.li-row:hover .li-row__menu-trigger,
.li-row:focus-within .li-row__menu-trigger { opacity: 1; }
.li-row__menu-trigger:hover     { background: #B3CAF4; }

/* accordion sub-row: this is where the accent bar still lives */
.acc-row.is-active              { border-left: 3px solid var(--accent); font-weight: 600; }
.acc-row:hover,
.acc-row.is-active:hover        { background: #DDE9FF; }

/* primary action: filled, not an outline pill */
.li-add {
  background: var(--baymaxblue, #1950B5);
  border: 1.5px solid var(--baymaxblue, #1950B5);
  border-radius: 8px;
  color: #FFFFFF;
}
.li-add:hover { background: #153F8F; border-color: #153F8F; }
